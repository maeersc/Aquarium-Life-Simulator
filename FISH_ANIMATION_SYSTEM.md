# Marine fish and resident animation architecture — v4.0.4 checkpoint

This is a 2D presentation service. It never advances biological time, consumes RNG, changes nutrition/health, spawns eggs, modifies inherited traits or writes player saves.

`assets/animation/fish-registry.json` assigns every registered marine fish to an explicit artistic motion family and three stage rates, with tail root/head protection and reviewed eye corrections. `build.py` regenerates `js/fish-animation-data.js`; tests reject unassigned new marine species. These rates/regions are artistic game calibrations, not experimentally verified swimming biomechanics. Five art-only reference fish are excluded; five held clownfish remain acquisition-held.

`AL.FishAnimation.update(f, rendererPosition, dt, desiredFacing)` stores its clock, beat, bank, state and 320-ms turn solely on `Renderer.positions`. Real velocity sets propulsion frequency. Actual Eat/Rest/Hide and existing reproductive labels select motion variants. Conditions become visual only after their existing onset and severity threshold, with carrier-only states not automatically exposing a symptom. Respiratory conditions, irritation and weakness have different motions; presentation never diagnoses or treats a fish.

`source` now prioritizes validated sixteen-frame production sheets for covered stages/varieties. Original natural Ocellaris benchmark and four-pose adult clownfish sources remain the unchanged reference/fallback authorities. Young clownfish, base marine fish and both expansion batches reuse their authored stage/state sources. Banggai's early display selects the existing developed-juvenile artwork, preserving the mouthbrooding simulation. `AL.ExpansionArt` applies central eye metadata before scaling and retains native-facing normalization. One Blue Assessor baby eye registration was corrected in raw left-facing coordinates; 25 v2.9 fish gained their previously absent living eye registrations for baby, juvenile and adult. Original PNG bytes remain unchanged.

Individual `AL.Patterns.sprite` output enters articulation before movement, so body bars and inherited identities are never independently regenerated per fin frame. Validated authored sixteen-frame cycles bypass procedural deformation. Only retained fallback poses use final-size rasters and thin column strips: the caudal hinge is fixed, tail columns shift by at most a few integer pixels, and authored upper/lower fin pixels flex slightly about an unchanged core. The head region and eye patch stay unchanged across procedural phases. Four-pixel transparent padding contains excursions. All image sampling uses nearest-neighbor. There is no synthetic eye, fin repaint, whole-body squash or 3D renderer.

Procedural fallback poses use a global 768-entry LRU. Source registration/raster caches are weakly keyed and limited per source/size. Image decoding and alpha readback happen outside the per-frame hot path on cache misses. Renderer scratch arrays retain sorted fish references and hitboxes, positions prune by frame stamp, and offscreen marine fish skip sprite/rig work. Conservative hitbox padding covers fin/turn motion. Selection expires after three real seconds; inspector lifetime remains independent. Biological outcomes are tested equal after different render counts with the same simulated interval; the test controls diagnostic receipt wall time rather than hiding differences in health or account values.

The standalone `fish-animation-review.html` loads art/model definitions without the game save/startup/main scripts. It constructs only throwaway specimen objects and supports all 94 IDs, designer varieties, three stages, both sides and state studies. It is not a store, breeding authorization, disease diagnosis or a way to acquire held livestock.

### Validated sheet contract and caches

`AL.FishAnimation.sheets` is part of the same service, not a second competing animator. Its library keys by biologicalID/stage/state/variety. A production record declares `path`, `sha256`, `frameWidth`, `frameHeight`, `columns`, `frameCount:16`, `order:[0..15]`, `framesPerSecond`, `anchor`, `facing`, optional existing-eye metadata and explicit validation evidence. The build checks original path, PNG header/cell dimensions, fileSHA, sixteen distinct recorded frame hashes, art-review evidence, state/stage/timing and completion accounting. It embeds native PNG dataURLs in ordered local classic-script chunks below8MB each, keeping the registry metadata small and every file below GitHub upload limits. The generator updates the existing game/gallery script order and removes only obsolete generated chunks. No network fetch, CDN, image recompression or separate animator is introduced. The browser validates actual decoded cells on first load and rejects blank/repeated poses. An LRU retains at most128 decoded sheets and1024 extracted frames. The earlier256-cell limit repeatedly evicted active poses in the250-fish mixed-species workload; the larger bounded cache avoids repeated rasterization. Performance evidence records cache hits, misses and evictions alongside frame times. Evicted images reload from the same bundled PNG while retained cells remain available; tests verify eviction, reloading and identical original pixels. Actual registered production PNGs now use this contract; current sheet counts and file-hash-matched browser evidence are in LIVESTOCK_16_FRAME_SPRITE_PRODUCTION_REPORT.md. Synthetic loader fixtures remain explicitly separate from animal artwork.

`source` selects the registered stage/variety swim sheet, with only explicit existing stage aliases and designer early-stage sharing permitted; otherwise it retains the original source. The metadata includes biological and designer identity. `draw` honors its centered anchor and bypasses the procedural rig. Pattern output retains authored metadata and separate frame identity, preventing an old fallback-frame pattern cache from replacing a new sheet cell. The existing pattern authority and inherited data are unchanged. `drawResident` handles coral/invertebrate sheets with fixed or mirrored anchors, never fish bending; dead calls always return to original mortality presentation. With no validated sheet, existing sprites/behavior remain. Some legacy coral groups remain unverified biological identities, and settled invertebrate baby images are not newly verified planktonic larvae.

Normal existing family cycles are now0.42–0.56Hz before actual-state/stage modifiers; normal requested16-slot rate is tested around6–10Hz, not a claim of16authored poses. Fin oscillation uses one cycle, normal displacement stays at most one scene pixel and added bob is zero. Rest/perch reduces rate; faster movement raises it; banked direction changes retain phase. These are artistic calibrations, not measured biological research. Old animation audit rate descriptions are historical.
